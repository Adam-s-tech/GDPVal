# Ce que ça mesure

## Qu'est-ce qu'une « tâche utile » ici ?

Une tâche utile, dans ce contexte, c'est un **livrable professionnel complet** : un document qu'un humain pourrait remettre à un client, à un collègue ou à une autorité sans avoir à le refaire de zéro.

Ce n'est pas :
- Répondre à une question (« Qu'est-ce qu'un contrat de bail ? »)
- Résumer un texte
- Générer quelques phrases sur un sujet

C'est :
- Rédiger un contrat de bail complet, conforme aux usages du secteur
- Produire un planning hebdomadaire détaillé pour un gestionnaire immobilier
- Créer un formulaire d'évaluation de risque, prêt à être utilisé

## Ce que ce dépôt observe

Ce dépôt teste si un assistant IA peut **aller au bout d'une tâche** — de la consigne au livrable final — sans aide humaine intermédiaire.

L'assistant reçoit une description de tâche et des fichiers de référence (exemples du secteur, modèles, données). Il doit ensuite produire un document professionnel autonomement.

## Exemple de tâche type

**Secteur : Immobilier**
**Tâche** : Rédiger une lettre d'intention (LOI) pour la location commerciale d'un local de 450 m² à Paris.
**Livrable attendu** : Un document Word de 2–3 pages, structuré selon les conventions juridiques françaises, incluant les clauses essentielles (loyer, durée, conditions suspensives).

→ Voir le dossier `outputs/` pour consulter les livrables produits lors de l'expérience.
